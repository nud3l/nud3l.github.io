# harz.dev

Personal website and blog built with [Docusaurus 3](https://docusaurus.io/).

### Prerequisites

- Node.js >= 20
- pnpm

### Installation

```
pnpm install
```

### Local Development

```
pnpm start
```

Starts a local development server and opens a browser window. Most changes are reflected live without restarting.

### Build

```
pnpm run build
```

Generates static content into the `build` directory.

### Deployment

Deployment to GitHub Pages happens automatically via GitHub Actions on push to `master`.
